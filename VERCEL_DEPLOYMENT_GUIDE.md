# Argus Vercel Deployment & Serverless RAG Guide

This guide details how Argus is structured for serverless deployment on Vercel with a fully functional RAG pipeline.

---

## 1. Architecture Overview on Vercel

```
                                  +------------------------------------+
                                  |         Vercel Edge Network        |
                                  +------------------------------------+
                                                    |
                                                    v
                                  +------------------------------------+
                                  |     AWS Lambda Serverless App      |
                                  |           (api/index.py)           |
                                  +------------------------------------+
                                     /             |                \
                                    /              |                 \
                                   v               v                  v
                       +----------------+  +---------------+  +-------------------+
                       | Volatile RAM   |  | 384-d Cosine  |  | Multi-Provider    |
                       | Zero-PII Mask  |  | Vector RAG    |  | LLM Bridge        |
                       | (Presidio+NER) |  | (vector_cache)|  | (Groq/OpenAI/RAG) |
                       +----------------+  +---------------+  +-------------------+
                                                   |                    |
                                                   v                    v
                                        +-------------------+  +------------------+
                                        | /tmp Write Enclave|  | Grounded L1 SRE  |
                                        | SQLite + Runbooks |  | Action Plan      |
                                        +-------------------+  +------------------+
```

### Why Standard ChromaDB / Ollama Fail on Vercel Without This Solution
1. **AWS Lambda Size Limit**: Vercel serverless has a strict 250MB uncompressed bundle limit. Heavy C++ bindings like `onnxruntime` (~180MB) and `chromadb` (~60MB) frequently exceed the quota or fail to build.
2. **Read-Only Root Filesystem**: Lambda instances run with `/var/task` mounted read-only. Standard database writes crash immediately.
3. **Localhost Isolation**: `http://127.0.0.1:11434` (Ollama) does not exist inside Vercel's ephemeral cloud functions.

## 2. Argus's Serverless RAG Solution

### A. Dual-Mode Vector Retrieval Engine (`rag_engine.py`)
- **Local Dev Mode**: Uses full native ChromaDB with HNSW cosine search.
- **Vercel Serverless Mode**: Seamlessly switches to `data/vector_cache.json` which pre-stores exact 384-dimensional dense vectors generated by `all-MiniLM-L6-v2` for all 37 runbooks and incidents. Queries are matched in under **2ms** using mathematical cosine similarity with 0 external C++ binaries.

### B. Multi-Provider LLM Bridge (`llm_bridge.py`)
- **Groq Cloud (Recommended for Vercel)**: Set `GROQ_API_KEY` for blazing-fast 80+ tokens/sec inference via `llama-3.3-70b-versatile` or `qwen-2.5-32b`.
- **OpenAI / OpenRouter**: Set `OPENAI_API_KEY` (and optional `OPENAI_BASE_URL`).
- **Remote Ollama**: Set `ARGUS_OLLAMA_ENDPOINT` pointing to your self-hosted or tunneled Ollama instance.
- **Serverless Grounded RAG Synthesizer (Built-in Zero-Key Fallback)**: If no external API keys are configured, Argus autonomously synthesizes grounded, token-preserving L1 SRE remediation plans directly from retrieved runbook chunks without crashing.

### C. Ephemeral Filesystem Boundary Manager (`config.py`)
Automatically routes all file writes and database operations to `/tmp/data`, `/tmp/storage_vault`, and `/tmp/generated_runbooks`, and copies bundled databases on cold start.

## 3. How to Deploy to Vercel

### Option 1: Deploy Using Vercel CLI (Fastest)

1. **Install Vercel CLI**:
   ```bash
   npm install -g vercel
   ```

2. **Login to Vercel**:
   ```bash
   vercel login
   ```

3. **Deploy from project directory**:
   ```bash
   cd /home/gkprabhav/Prabhav/genai_fin
   vercel
   ```
   Follow the interactive prompts:
   - *Set up and deploy?* **Y**
   - *Which scope?* Select your personal account or team.
   - *Link to existing project?* **N**
   - *Project name?* `argus-sre` (or press Enter)
   - *In which directory is your code located?* `./` (press Enter)

4. **Deploy to Production**:
   ```bash
   vercel --prod
   ```

---

### Option 2: Deploy via GitHub / GitLab Integration

1. Initialize a Git repository and push your code:
   ```bash
   git init
   git add .
   git commit -m "feat: Argus Vercel Serverless RAG Enclave"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```

2. Go to [https://vercel.com/new](https://vercel.com/new).
3. Import your GitHub repository.
4. Leave framework preset as **Other**.
5. Click **Deploy**.

## 4. Configuring Cloud LLMs on Vercel (Optional but Recommended)

In your Vercel Dashboard -> **Project Settings** -> **Environment Variables**, add:

| Variable | Recommended Value | Description |
|---|---|---|
| `GROQ_API_KEY` | `gsk_...` (free at console.groq.com) | Enables ultra-fast 80+ tokens/sec LLM action plan generation |
| `GROQ_MODEL` | `llama-3.3-70b-versatile` | High-quality reasoning model |
| `OPENAI_API_KEY` | `sk-...` | Optional: OpenAI or OpenRouter key |
| `OPENAI_MODEL` | `gpt-4o-mini` | Optional: OpenAI model identifier |
| `ARGUS_LEAD_MASTER_KEY` | `YourSecretMasterKey` | Master key to unlock Cryptographic Rulebook Enclave |

*(Note: Even with 0 environment variables set, vector retrieval and serverless grounded action plan synthesis work 100% out of the box).*
